

В рамках спринта реализовано API-тестирование сервиса Яндекс Самокат.

Добавлены тесты на:
- успешное создание курьера;
- создание дубликата курьера;
- создание курьера без обязательных полей;
- успешную авторизацию курьера;
- авторизацию с неверным логином или паролем;
- авторизацию без обязательных полей;
- авторизацию несуществующего пользователя;
- создание заказа с различными вариантами цвета через параметризацию;
- получение списка заказов.

В тестах выполняется проверка статус-кодов и содержимого ответов API.
Для генерации уникальных данных используется вспомогательный генератор курьеров.
Добавлена интеграция с Allure Report.
